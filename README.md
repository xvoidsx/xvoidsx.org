# xvoidsx.org

The xvoidsx collective hub — who we are, what we build, and how to support
it. Serves at **xvoidsx.org** via GitHub Pages (the `CNAME` file sets the
custom domain).

xvoidsx is a small independent collective building **navi** (an agent-native
Linux distro), open software, smallweb tools, and computers that feel
personal again — for ourselves, and for the whole Linux and web ecosystem.

Static single-page site: `index.html` + `assets/`. No build step — edit,
commit, and it deploys.

Part of the xvoidsx domain family:
- **xvoidsx.org** — the collective (this repo)
- **navi.xvoidsx.org** — the navi distro product site
- **threelains.xyz** — Lain's personal site
